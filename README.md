# BÀI THỰC HÀNH 01: ỨNG DỤNG AI TRONG CẤU HÌNH VÀ GIẢI QUYẾT SỰ CỐ

* **Môn học:** Nền tảng Công nghệ số | **Lớp:** CT005/F01 | **Nhóm:** 08

---

## 1. Mô Tả Nội Dung Thực Hành
Bài thực hành ứng dụng các công cụ Generative AI (Google Bard/Gemini, ChatGPT, Canva AI) để hỗ trợ công việc kỹ thuật cơ bản:
* **Khảo sát phần cứng & Cấu hình:** Kiểm tra thông số CPU, RAM, SSD; cài đặt Notepad++ và chạy script Python (`hello.py`).
* **Giải quyết sự cố kỹ thuật:** Sử dụng lệnh CMD (`ipconfig`) xử lý lỗi mất Wi-Fi và khắc phục giới hạn bộ nhớ khi mở file lớn trên Notepad++.
* **Sáng tạo & Đạo đức AI:** Thiết kế Infographic bằng Canva AI và phân tích trách nhiệm sử dụng AI minh bạch theo khung DigComp 2.2.
